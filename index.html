GAME THEME DIARY ─ 好きなゲームのUIで日記を書く

Game Theme Diary とは

好きなゲームのメニュー画面の雰囲気で日記が書ける、無料のWebアプリです。登録やインストールは要りません。ゲームを選ぶと、そのゲーム風の画面で、その日の気分と日記を書けます。

テーマは 44作品・63種類 から選べます。

日記はお使いの端末のブラウザ(localStorage)に保存され、サーバーには送られません。ソースは GitHub で公開しています。

このサイトについて

ここにあるテーマは、各ゲームのメニュー画面の雰囲気をまねて、個人が趣味で作った非公式のファンメイドです。各ゲームの制作会社・発売元とは、一切関係がありません。公式の画像・ロゴ・キャラクター・音声・フォントは使っておらず、見た目はすべて自作のコード(CSS/SVG)で、似せて作ったものです。

ゲームのタイトルや名称は、それぞれの権利者の商標または登録商標です。「○○風」という表記は、そのゲームの画面の雰囲気を説明するためのもので、公式を名乗るものではありません。営利目的では運営していません。権利者の方からご連絡があった場合は、速やかに対応します(GitHub の Issues へお知らせください)。
