# Game Theme Diary

好きなゲームのメニュー画面風の見た目で、日記を書くWebアプリです(`game-theme-diary/`)。ビルド不要の静的HTMLで、日記は各端末のブラウザ(localStorage)に保存されます。サーバーへは送信しません。

## 非公式ファンメイドについて

- ここにあるテーマは、各ゲームのメニュー画面の**雰囲気をまねて**、個人が趣味で作った**非公式のファンメイド**です。各ゲームの制作会社・発売元とは一切関係がありません。
- 公式の画像・ロゴ・キャラクター・音声・フォントは使っていません。見た目はすべて自作のコード(CSS / SVG / JavaScript)と、Google Fonts の書体で作っています。
- ゲームのタイトルや名称は、それぞれの権利者の商標または登録商標です。「○○風」という表記は、画面の雰囲気を説明するためのもので、公式を名乗るものではありません。
- 営利目的では運営していません。権利者の方からご連絡があった場合は、速やかに対応します(GitHub の Issues へお知らせください)。

## テーマを追加するときのルール

1. ゲームの名前は、ロゴの見た目に寄せず、**「○○風」の表記**にする(`game-theme-diary/theme-switch.js` の `DISPLAY` に追加)。
2. 画像・ロゴ・キャラクター・台詞・固有の文言を、そのまま使わない。ロゴ風の題字や、ゲーム内の名台詞・演出文言は、日記向けの言葉に置き換える。
3. 日記データは共通の `diary-shared-v1`(localStorage)を使う。
4. テーマ1つにつき、PRを1つ作る。`theme-switch.js` を編集する前に `main` を取り込む。
